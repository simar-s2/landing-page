# Landing Page

A marketing landing page built from a design spec to practice layout with
Flexbox. One of [The Odin Project](https://www.theodinproject.com/) foundations
exercises.

![Landing page](docs/landing.png)

## Run it

Open `index.html` in a browser. No build step.

## How it works

Five stacked sections, each a Flexbox row or column:

1. **Navbar**: logo left, links right, on a dark background
2. **Hero**: headline and call-to-action button beside a placeholder image
3. **Info**: four feature cards in a row with image placeholders
4. **Quote**: large centred pull quote on a light background
5. **Call to action**: a coloured band with a sign-up button, then the footer

Consistent horizontal padding (`10vw`) keeps every section aligned.
